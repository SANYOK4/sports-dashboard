# DashMatch Project# ⚽ DashMatch — Sports Dashboard

Сучасний веб-додаток для перегляду футбольних результатів у реальному часі. Проект розроблений на **Angular** з використанням сучасних підходів (Standalone Components, Signals, CSS Animations).

## 🚀 Функціонал

* **🏆 Live-режим:** Матчі, що йдуть прямо зараз, підсвічуються червоним кольором та мають пульсуючу анімацію.
* **📂 Розумна фільтрація:** Сортування матчів за лігами (АПЛ, Ла Ліга, УПЛ тощо) через бічну панель.
* **🔍 Миттєвий пошук:** Пошук команд у реальному часі без перезавантаження сторінки.
* **✨ Інтерактивні картки:** Детальна інформація про голи та події матчу розгортається при кліку (акордеон).
* **🎨 Сучасний UI:** Темна тема (Dark Mode), градієнти, адаптивний дизайн.

## 🛠 Технології

* **Frontend:** Angular (Latest version), TypeScript
* **Стилізація:** CSS3 (Flexbox, CSS Variables, Keyframe Animations)
* **Архітектура:** Standalone Components, Input/Output, Event Emitters

## 📦 Як запустити проект

1.  Клонуйте репозиторій:
    ```bash
    git clone [https://github.com/SANYOK4/sports-dashboard.git](https://github.com/SANYOK4/sports-dashboard.git)
    ```
2.  Встановіть залежності:
    ```bash
    npm install
    ```
3.  Запустіть локальний сервер:
    ```bash
    ng serve
    ```
4.  Відкрийте у браузері: `http://localhost:4200`
